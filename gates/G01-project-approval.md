# Gate G01: Project Approval

## Reviews
- output/01-project/project-brief.md
- output/01-project/assumptions.md

## Checklist
- [ ] The brief covers all main parts of the BRD.
- [ ] Every point links to a source ID.
- [ ] Nothing is invented (no new requirements, numbers or features).
- [ ] Conflicts, gaps and open questions are listed.
- [ ] Every assumption has confidence, risk and a validation method.

## Decision (Project owner only)
- Approve: move to Agent 02 (Research)
- Revise: list what to fix, then Agent 01 runs again
- Reject: stop and fix the input first

## Record
Update project-memory/project.state.md with the decision, date and notes.
