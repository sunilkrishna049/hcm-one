# Skill: Design Decision Log

## Description
Records important design decisions with reasons, so they can be traced and shown in the case study.

## Role
Act as a design lead who documents why decisions were made.

## Inputs
- The decision, the options considered and the evidence behind it.

## Instructions
1. Add a new entry to project-memory/design-decisions.md. Create the file if it does not exist.
2. Never edit or delete old entries. If a decision changes, add a new entry that references the old one.

## Output
Entry format:
- ID: DEC-001 (increase by one each time)
- Date
- Decision
- Options considered
- Reason
- Evidence or source (BRD ID, research section or artifact)
- Proposed by (agent name or Project owner)
- Status: Proposed or Approved

## Rules
- Agents can only add decisions as "Proposed".
- Only Project owner can mark a decision "Approved".
